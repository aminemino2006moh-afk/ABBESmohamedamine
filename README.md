Description du Site (Tropicaux)
Tropicaux est une interface de boutique en ligne élégante et réactive,
spécialement conçue pour présenter et vendre des produits tropicaux de qualité (fruits).
Le site se distingue par son design captivant et audacieux qui marie des verts naturels et des ors riches,
reflétant l'atmosphère tropicale et la haute qualité des produits.
Le site offre une expérience utilisateur fluide grâce à sa navigation simple, 
son système de filtrage des produits et un processus de commande simplifié.


les instruction d'utilisation:
1. Inscription et Connexion
Créer un compte : Allez sur la page Inscription -> Remplissez vos informations -> Cliquez sur Créer.
Accéder au site : Allez sur la page connexion -> Saisissez votre email et mot de passe -> Cliquez sur Se connecter.
2. Navigation et Produits
Filtrage : Utilisez les boutons de menu en haut de la page (ex: Chine, Tous) pour trier les produits par région.
Détails : Cliquez sur le bouton Détails d'un produit pour voir sa description complète et son prix.
3. Finalisation de commande
Sélection : Dans la fenêtre de détails, cliquez sur Finaliser.
Confirmation : Sur la page Order, saisissez vos coordonnées -> Cliquez sur Valider.
Fin : Un message de confirmation s'affichera, puis le site vous redirigera automatiquement vers l'Accueil.
